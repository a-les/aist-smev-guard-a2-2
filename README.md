# «Щит-АИСТ / СМЭВ-Guard & ViPNet Z3»

**Защищённый комплекс межведомственного электронного взаимодействия и безопасности региональных ИИ-сервисов госсектора**

Проект разработан в рамках производственной практики студентами 5 курса кафедры «Компьютерная безопасность» ФГАОУ ВО «ОмГУ им. Ф. М. Достоевского» по заказу ГУИТ Омской области.

Комплекс реализует контур безопасности перед региональной языковой моделью (LLM) «АИСТ», обрабатывающей обращения граждан (по Федеральному закону № 59-ФЗ) и запросы СМЭВ 3.0 поверх ГОСТ-туннелей ViPNet Coordinator.

---

## Ключевые защитные механизмы

1. **Контур защиты персональных данных (152-ФЗ):**
   * Гибридное распознавание 15 категорий ПДн РФ с математической верификацией контрольных разрядов (СНИЛС mod 101, ИНН mod 11, ОГРН, счета ЦБ РФ, полисы ОМС и карты «Мир» по алгоритму Луна, коды ОКАТО паспортов РФ, УИН ГИС ГМП).
   * Падежная морфологическая нормализация ФИО для корректного сохранения контекста (кореференции) в обращении.
   * Криптографическое хранилище обратимой токенизации (*Reversible PII Token Vault*) на базе AES-256-GCM и деривации ключей HKDF-SHA256 с гарантией **0.0% межсессионных утечек (Cross-Citizen PII Leak)**.

2. **Входной фильтр конвертов СМЭВ 3.0:**
   * Блокировка XML-инъекций (XXE, Billion Laughs / XML Bomb, лимит глубины AST $\le 16$).
   * Фильтрация сетевых векторов SSRF/LFI и обращений к внутренним диапазонам RFC 1918 / DNS Rebinding.
   * Контроль вложений (MIME, SHA-256, эвристика активных скриптов PDF и макросов MS Office).

3. **Трёхкаскадный экран защиты LLM (МД ФСТЭК России от 12.04.2026):**
   * *Каскад 1 (< 0.5 мс):* канонизация NFKC, удаление скрытых символов Zero-Width / Bidi, нормализация гомоглифов и автоматический декодер Base64/Hex/Rot13/Leetspeak с сигнатурным анализом.
   * *Каскад 2 (< 2.0 мс):* нейросетевая классификация и косинусный скоринг по векторной базе джейлбрейков и косвенных инъекций (Indirect RAG Injection).
   * *Каскад 3 (Output Guard):* контроль ответов LLM перед детокенизацией, блокировка утечки канареечных меток (`[CANARY-GOV-AIST-...]`), несанкционированного вызова инструментов (*Tool-Use Hijacking*) и юридически ничтожных финансовых обещаний.

4. **Формальная верификация сетевых конфигураций (Z3 SMT Solver):**
   * Математическое доказательство непротиворечивости правил фильтрации ViPNet (`BitVec32` / `BitVec16`).
   * Автоматическое выявление затенения правил (*Rule Shadowing*, CWE-561) и утечек открытого трафика мимо ГОСТ-туннелей (*Split-Tunneling Cleartext Leak*, CWE-319 / мера ЗКС.1).
   * Экспорт находок в международный формат SARIF 2.1.0.

5. **Расчёт показателя защищённости ГИС ($U_{\text{зи}}$):**
   * Двухконтурная модель по Приказу ФСТЭК России № 117 (в ред. № 137).
   * Автоматическое обнуление блокирующего множителя ($I_{\text{block}} = 0 \to U_{\text{зи}} = 0.0$) при обнаружении критических дефектов сетевого периметра.

6. **Неизменяемый журнал аудита событий ИБ:**
   * Реализация стандарта ГОСТ Р 59548-2022 на базе отечественной хеш-функции «Стрибог-256» (ГОСТ Р 34.11-2012).
   * Сквозная криптографическая цепочка записей и построение дерева Меркла (*Merkle Inclusion Proof*).

## Архитектура монорепозитория

```
aist-smev-guard-a2-2/
├── src/
│   ├── models/contracts.py         # Единые Pydantic v2 контракты данных
│   ├── pii/
│   │   ├── ru_gov_pii_detector.py  # Гибридный детектор ПДн РФ с проверкой контрольных сумм
│   │   └── reversible_token_vault.py # Криптохранилище обратимой токенизации (AES-GCM + HKDF)
│   ├── smev/
│   │   └── smev3_envelope_validator.py # Валидатор конвертов СМЭВ 3.0 (анти-XXE, анти-SSRF)
│   ├── vipnet/
│   │   ├── ast_opa_uzi_engine.py   # Структурный парсер ViPNet и калькулятор Uзи
│   │   └── z3_smt_tunnel_verifier.py # SMT-верификатор сетевых туннелей на Z3
│   ├── guardrails/
│   │   └── three_stage_prompt_shield.py # 3-каскадный защитный экран от Prompt Injection
│   ├── redteam/
│   │   └── gov_garak_pyrit_orchestrator.py # Комплекс стресс-тестирования Red-Teaming
│   ├── crypto/
│   │   └── fstec_streebog_audit_logger.py # Журнал аудита ГОСТ Р 34.11-2012 («Стрибог-256»)
│   └── api/
│       └── main.py                 # Промышленный FastAPI-шлюз с метриками Prometheus
├── pipelines/                      # ML-пайплайны подготовки данных и дообучения
├── tests/                          # Модульные, интеграционные и нагрузочные тесты
├── migrations/                     # DDL-схемы PostgreSQL 16 с RLS и триггерами неизменяемости
├── policies/                       # Политики Open Policy Agent (Rego)
└── pyproject.toml                  # Спецификация проекта и зависимости
```

## Развертывание и тестирование

### 1. Подготовка окружения
```bash
python -m venv .venv

# Активация окружения (Windows PowerShell):
.\.venv\Scripts\Activate.ps1

# Установка зависимостей:
pip install -e .
pip install -e ".[dev]"
```

### 2. Запуск автотестов
```bash
pytest -v --tb=short
```
